/* Fuji Classic Chrome Film Simulation */
filter: contrast(1.05) saturate(0.85) brightness(1.02) sepia(0.08);

/* 效果：
- contrast(1.05) → 微增强对比，模拟胶片感光
- saturate(0.85) → 降低饱和度，Classic Chrome 特征
- brightness(1.02)→ 微提亮，补偿暗部
- sepia(0.08) → 轻微暖棕调，复古胶片感
*/

10 — EFFECTS

视觉效果

胶片的不完美就是它的美 — 颗粒、漏光、褪色。

胶片颗粒 Film Grain

全页面叠加的 SVG 噪点纹理（opacity: 0.04），使用 feTurbulence 滤镜，模拟真实胶片颗粒。

漏光 Light Leak

右上角渐变的暖色光晕，模拟暗房失误或胶片相机漏光。用在主界面和大卡片上。

11 — MOTION

动效系统

拍立得的"吐片"感 — 拍下快门后照片缓缓滑出。

快门 Click
150ms ease-out

按钮点击、标签切换、选中态

对焦 Focus
200ms ease-out

输入聚焦、卡片浮起、悬停高亮

吐片 Eject
300ms cubic-bezier(0.34,1.56,0.64,1)

拍立得弹出、对话框出现、照片预览进入

翻页 Flip
400ms cubic-bezier(0.16,1,0.3,1)

视图切换、照片翻页、胶片条滚动

吐片动画描述

吐片 Eject — 使用带弹性的 cubic-bezier(0.34, 1.56, 0.64, 1) 缓动曲线。
拍立得照片从底部滑入 + 轻微弹跳，模拟即时成像照片从相机口中缓缓吐出的物理感。
同时配合 transform: translateY(20px) → translateY(0) + opacity: 0 → 1。

设计原则

01

即拍即得

每张照片都以拍立得形态呈现 — 白色边框、手写标注、微微倾斜。浏览照片就像翻阅一叠拍立得。

02

Classic Chrome

默认应用富士 Classic Chrome 色彩 — 低饱和暖棕调。让数字照片拥有胶片的温度和质感。

03

不完美的美

胶片颗粒、漏光、微微的倾斜和堆叠 — 拥抱模拟时代的不完美，它是温度的来源。
